# Biblioteca de Hábitos

HabitFlow é um sistema simples para criar, acompanhar e manter hábitos no dia a dia. A biblioteca permite começar escolhendo um objetivo e adicionando um hábito pronto em poucos segundos.

Objetivos iniciais: saúde, estudos, produtividade, bem-estar e organização. Cada template possui nome, descrição, categoria, frequência sugerida, cor, dificuldade, tempo estimado e benefício.

Rotas: `/habit-library`, `/habit-library/objective/{slug}` e `POST /habit-library/add`.
