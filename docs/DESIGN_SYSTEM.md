# Design System HabitFlow

v5.3 adiciona mensagens premium (`hf-message-*`), campos de senha (`hf-password-*`) e ilustrações contextuais SVG inline. Estados usam cores sólidas de alto contraste para sucesso, info, aviso, erro e banco/infra.

## v5.5 — Feedback premium
Toasts usam `.hf-toast-*`; modais usam `.hf-feedback-modal`; estados vazios/erro usam `.hf-empty-state` e `.hf-error-state`. Todos devem manter contraste, foco visível, teclado e responsividade mobile.
