# Manual do Usuário HabitFlow

1. O HabitFlow é um sistema para criar hábitos, ver o que fazer hoje e acompanhar progresso.
2. Crie sua conta em `/register`.
3. Escolha um objetivo na biblioteca ou onboarding.
4. Adicione um hábito pronto ou crie um hábito próprio.
5. Marque o hábito no Dashboard quando concluir.
6. Veja seu progresso diário no Dashboard e em `/progress`.
7. Use `/reports` para entender evolução e consistência.
8. Use `/habit-library` para começar mais rápido com sugestões.
9. O plano Free permite começar com até 5 hábitos; o Premium libera mais limites e relatórios avançados.
10. Peça suporte em `/support`.
11. Solicite dados, exportação ou exclusão pela área de perfil/suporte conforme LGPD.
